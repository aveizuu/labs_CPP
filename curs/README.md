## Установка и запуск

1. Скачайте и установите SFML 2.6.2 для Windows:
   - Перейдите на официальный сайт SFML
   - Скачайте SFML 2.6.2 для Windows
   - Распакуйте архив в удобное место

2. Клонируйте репозиторий:

3. Откройте проект в Visual Studio:
   - Откройте файл `Arcanoid.sln`
   - В свойствах проекта (Project Properties) проверьте пути к SFML:
     - C/C++ -> General -> Additional Include Directories: путь к include папке SFML
     - Linker -> General -> Additional Library Directories: путь к lib папке SFML
     - Linker -> Input -> Additional Dependencies: добавьте все .lib файлы из lib папки SFML

4. Соберите и запустите проект:
   - Выберите конфигурацию Release
   - Нажмите Build -> Build Solution
   - Скопируйте все .dll файлы из bin папки SFML в папку с .exe файлом
   - Запустите Arcanoid.exe

## Управление
- **Стрелки влево/вправо** — движение каретки
- **Пробел** — отпускание липкого шара

## Типы бонусов
- **OneTimeBottomBonus** — одноразовое дно: первый раз шарик отскакивает от дна, бонус исчезает
- **ExtraBallBonus** — второй шар (максимум 2 шара одновременно)
- **StickyBallBonus** — липкий мяч: следующий контакт с ракеткой — шар прилипает, отпускается по пробелу, летит в обратную сторону. Если в момент получения бонуса в игре два шара, при первом касании ракетки все остальные шары удаляются, кроме того, который прилип.
- **IncreaseRacketBonus** — увеличение размера каретки на 3 секунды
- **SpeedBallBonus** — ускорение всех шаров на 3 секунды

## Типы блоков
- Обычные (1–3 жизни, разный цвет)
- Неразрушаемые (тёмно-зелёные)
- Ускоряющие (красные)
- Бонусные (синие)
