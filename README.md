### Курсовой проект: Игра "Арканоид"
**Ветка:** `curs`

Итоговая работа представляет собой реализацию классической аркадной игры **Arkanoid**. 
* **Особенности:** Применение объектно-ориентированного подхода, обработка коллизий, игровой цикл и отрисовка графики.
