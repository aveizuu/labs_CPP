### Курсовой проект: Игра "Арканоид"
**Папка:** `cours`

Итоговая работа представляет собой реализацию классической аркадной игры **Arkanoid**. 
* **Особенности:** Применение объектно-ориентированного подхода (классы платформы, мяча, блоков), обработка коллизий, игровой цикл и отрисовка графики.
